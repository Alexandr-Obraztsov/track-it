# Тестирование Backend

## Обзор

Все API routes покрыты тестами с изоляцией каждого теста. Используются моки для базы данных и middleware.

## Структура тестов

```
src/__tests__/
├── setup.ts                    # Настройка тестов и моков
├── mocks/
│   ├── database.ts            # Моки для TypeORM
│   └── middleware.ts          # Моки для middleware
├── helpers/
│   └── testHelpers.ts         # Вспомогательные функции
└── routes/
    ├── auth.test.ts           # Тесты аутентификации
    ├── users.test.ts          # Тесты пользователей
    ├── chats.test.ts          # Тесты чатов
    ├── tasks.test.ts          # Тесты задач
    ├── comments.test.ts       # Тесты комментариев
    ├── labels.test.ts         # Тесты меток
    ├── roles.test.ts          # Тесты ролей
    └── notifications.test.ts  # Тесты уведомлений
```

## Запуск тестов

```bash
# Все тесты
pnpm test

# Конкретный файл
pnpm test -- auth.test.ts

# В режиме watch
pnpm test:watch

# С покрытием
pnpm test:coverage
```

## Добавление новых тестов

При добавлении новых routes:
1. Создайте файл `routes/newRoute.test.ts`
2. Используйте моки из `mocks/`
3. Покройте все сценарии (успех, валидация, ошибки)
4. Убедитесь, что тесты изолированы

## Пример теста

```typescript
describe('GET /api/resource/:id', () => {
  it('should return resource by id', async () => {
    const mockResource = { id: 1, name: 'Test' };
    mockRepository.findOne.mockResolvedValue(mockResource);

    const response = await request(app)
      .get('/api/resource/1')
      .set('Authorization', 'Bearer test-token');

    expect(response.status).toBe(200);
    expect(response.body.id).toBe(1);
  });
});
```
