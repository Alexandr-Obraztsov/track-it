# Руководство по отладке

## Debug Panel в приложении

В приложении добавлен **Debug Panel** - инструмент для просмотра логов прямо в Telegram Mini App.

### Как открыть Debug Panel

1. В правом нижнем углу приложения есть красная кнопка с иконкой жука 🐛
2. Нажмите на неё, чтобы открыть панель отладки

### Что показывает Debug Panel

- **Статус сети** (Online/Offline) - показывает, есть ли подключение к интернету
- **Все логи консоли** - перехватывает console.log, console.error, console.warn, console.info
- **Сетевые запросы** - показывает все HTTP запросы с их статусами и временем выполнения
- **Детали ошибок** - полная информация об ошибках сети и API

### Функции Debug Panel

- **Test API** - кнопка для проверки доступности API сервера
- **Clear** - очистить все логи
- **Закрыть** - закрыть панель

### Что искать при ошибке "Network Error"

1. **Проверьте статус сети** - должен быть "online"
2. **Посмотрите последние сетевые запросы** - найдите запрос с ❌
3. **Проверьте детали ошибки** - там будет указан URL, метод, код ошибки
4. **Используйте Test API** - проверьте, доступен ли сервер

### Типичные проблемы

#### CORS Error
```
Access to XMLHttpRequest ... has been blocked by CORS policy
```
**Решение:** Проверьте настройки CORS на бекенде, убедитесь что `CORS_ORIGIN` включает ваш домен

#### Network Error
```
ERR_NETWORK или Network Error
```
**Решение:** 
- Проверьте, что бекенд запущен
- Проверьте URL API в логах
- Проверьте доступность сервера через Test API

#### Timeout
```
timeout of 10000ms exceeded
```
**Решение:** Сервер не отвечает в течение 10 секунд, проверьте доступность

## Логи на бекенде

Бекенд также логирует все запросы авторизации:

```
🔐 Auth request: { origin, userAgent, hasInitData, ... }
✅ Auth successful: { userId, telegramId, ... }
❌ Telegram auth error: { message, stack, ... }
```

Проверьте логи бекенда для детальной информации.

## Проверка подключения

### Локально
```bash
curl http://localhost:3001/health
# Должно вернуть: OK
```

### В Telegram Mini App
Используйте кнопку "Test API" в Debug Panel

## Настройка для продакшена

1. Убедитесь, что `VITE_API_URL` установлен в `.env` фронтенда
2. Убедитесь, что `CORS_ORIGIN` включает домен вашего фронтенда
3. Проверьте, что бекенд доступен из интернета
4. Используйте HTTPS для продакшена
